# Проверка версии 0.1.3

- 25 публичных тестов прошли. Проверены обработка неполных и некорректных схем, сохранение предыдущего результата при ошибке и полный сценарий для обеих площадок на синтетических Excel-формах.
- Сравнены результаты CLI и Windows-сборки. Совпали порядок листов, заголовки и значения всех 49 листов Евдаково и 39 листов ЭПИ. Среди контрольных значений — заказ массой 42, остаток 2,5 т после конвертации из 2500 кг и расход промывочного материала 0,5.
- Сборка проверена на Windows 10 x64 с очищенным PATH и отключённым внешним окружением Python. В обоих прогонах процесс загрузил собственный `python312.dll` из временной папки PyInstaller.
- Power Query M представлен историческими запросами. Полное обновление запросов в Excel в рамках проверки релиза не выполнялось.
