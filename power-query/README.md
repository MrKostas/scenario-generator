# Исторические запросы Power Query M

Папки `evdakovo/` и `epi/` содержат 68 авторских M-запросов из Excel-реализации проекта. Имя файла соответствует имени запроса. Коды поиска Excel-форм заменены демонстрационными. Для просмотра откройте `.pq` как текст. Для переноса в Power Query создайте по запросу на файл и вставьте выражение в Advanced Editor.

- Для каждого набора создайте параметр `SourceFolder` и запрос `FolderContent = Folder.Files(SourceFolder)`. Запросы используют поля `Name` и `Content` при поиске и чтении файлов.
- Сначала загрузите справочники. От `Material` зависят категории материалов, `MaterialGroup_materials` и поступления. `MaterialGroup` использует `MaterialGroup_materials`. Заказы опираются на `Scenario` и `MaterialGroup`. Трубопроводы, линии и группы оборудования также образуют цепочки запросов.
- Запросы сохраняют исторические формы и правила по каждой площадке. Некоторые ссылаются на параметры или вспомогательные запросы Excel-книги. Для полного обновления требуются совместимые формы и соответствующая конфигурация. Синтетические файлы в релизе предназначены для текущих Python-пайплайнов.
